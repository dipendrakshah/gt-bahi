# ADR 0005 — Hybrid NPR subscription plus capped attach

- Status: accepted
- Date: 2026-09-18

## Context

Pure software at Tally prices cannot fund a cloud team. Uncapped GMV take-rate looks like Daraz.

## Decision

Monthly/yearly subscription in NPR plus a capped matcher attach (target 0.4%, cap NPR 8,000/month in year 1) or a per-match fee. Implementation fees for multi-branch. CA per-client seats.

## Consequences

Pricing page is more complex. Finance must report subscription vs attach separately.
