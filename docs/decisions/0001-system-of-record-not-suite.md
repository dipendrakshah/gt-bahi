# ADR 0001 — System of record, not a suite

- Status: accepted
- Date: 2026-09-18

## Context

The originating ask bundled accounting, API, MCP, storefront, and social chat agents.

## Decision

Bahi is the order-to-VAT ledger. API and MCP are interfaces. Storefront and chat are clients. We will not resource a theme shop or a general chatbot in year one.

## Consequences

Faster path to CA trust. We will look “smaller” than Blanxer on marketing sites. That is acceptable.
