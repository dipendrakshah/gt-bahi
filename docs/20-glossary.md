# 20 — Glossary

| Term | Meaning in this repo |
|---|---|
| AD | Gregorian calendar |
| ADR | Architecture / product decision record |
| Agent | Software client (chat or MCP) acting with a scoped token |
| ARPU | Average revenue per paying organization per month |
| Bahi | Working product name; bound ledger |
| BS | Bikram Sambat |
| CA | Chartered accountant (Nepal) |
| CBMS | IRD Central Billing Monitoring System |
| Channel | Where an order is captured (web, POS, IG, WA, phone) |
| COD | Cash on delivery |
| Design partner | Discounted early org whose job is to break the product |
| Fiscal document | Invoice, credit note, or other numbered tax document |
| Front door | Surface that captures demand (Blanxer, Woo, chat) |
| FY | Nepal fiscal year Shrawan–Ashadh unless marked |
| ICP | Ideal customer profile |
| IRD | Inland Revenue Department, Nepal |
| Matcher | Service that links rail payments to orders/invoices |
| MCP | Model Context Protocol — standard for tool access by AI clients |
| MDR | Merchant discount rate charged by a payment rail |
| NCHL | Nepal Clearing House Limited |
| NPR | Nepalese rupee |
| Operate | Default paid tier |
| Order | Pre-fiscal commercial document |
| PAN | Permanent account number |
| PSP / PSO | Payment service provider / operator (NRB licenses) |
| QR | Usually Fonepay or NEPALPAY merchant QR |
| Rail | eSewa, Khalti, Fonepay, ConnectIPS, bank, cash |
| System of record | The database other systems must not contradict |
| Take-rate | Percent of GMV or matched payments charged by software |
| TDS | Tax deducted at source |
| Tenant | One organization’s isolated books |
| Widget | Embeddable checkout / chat client |
| Woo | WooCommerce |
